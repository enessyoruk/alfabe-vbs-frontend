# Alfa-β Akademi — Veli ve Öğretmen Bilgi Sistemi

Alfa-β Akademi özel öğretim kurumu için geliştirilmiş web uygulaması. Kurumun tanıtım sitesini, veli panelini, öğretmen panelini ve yönetici akışlarını tek arayüzde toplar.

Canlı site: [alfabe-vbs-frontend.vercel.app](https://alfabe-vbs-frontend.vercel.app)

API katmanı ayrı repodadır: [alfabe-vbs-backend](https://github.com/enessyoruk/alfabe-vbs-backend)

## Ne işe yarar

- Kurum tanıtım sayfası, KVKK ve gizlilik metinleri
- Veli, öğretmen ve yönetici için ayrı giriş
- Öğretmen: sınıflar, yoklama, ödev, sınav, rehberlik, tatil ve bildirimler
- Veli: öğrenci bilgisi, devam, ödev, sınav sonuçları, rehberlik notları, ödemeler ve duyurular

## Teknolojiler

- Next.js 14 (App Router)
- React 18 ve TypeScript
- Tailwind CSS
- Radix UI

## Yerel çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda [http://localhost:3000](http://localhost:3000) adresini açın.
